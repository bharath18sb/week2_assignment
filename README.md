# Week 2 – Data Structures & File Handling

This repository contains the assignments for Week 2 of my Python course. The work focuses on data structures, file handling, and basic CRUD operations.

## Topics Covered

* Lists
* Tuples
* Sets
* Dictionaries
* File I/O
* CSV
* JSON
* Exception Handling
* CRUD Operations

## Assignments

### Part A: Small Programs

1. **List CRUD Operations (`01_list_crud.py`)** - Performs Create, Read, Update, Delete on a list.
2. **Dictionary Word Frequency (`02_word_frequency.py`)** - Uses a dictionary to count word occurrences in input text.
3. **Pattern Using Nested Loops (`03_pattern.py`)** - Demonstrates nested loops by printing a star pattern.
4. **Largest and Smallest Number (`04_largest_smallest.py`)** - Finds max/min in a list using loop logic.
5. **Sorting (`05_sort_lambda.py`)** - Sorts a list using `sort()` and a `lambda` key.

### Part B: Main Assignments

* **Contact Book (`06_contact_book.py`)** - Dictionary-based contact management.
* **Word Counter (`07_word_counter.py`)** - Counts words, lines, and chars in `sample.txt`.
* **JSON File Reader (`08_json_reader.py`)** - Loads and prints data from `data.json`.

### Part C: Mini Project

* **Student Management System (`student_management/student_management.py`)** - CSV-based student record system with persistent storage.

## Technologies Used

* Python
* CSV
* JSON
* File Handling

## How to Run

Navigate to the project folder in your terminal and run individual scripts:

```bash
python 01_list_crud.py
```

To run the Student Management System:

```bash
cd student_management
python student_management.py
```

## Learning Outcome

These assignments provided hands-on practice with core Python data structures, file manipulation, JSON/CSV formats, and essential CRUD logic.
